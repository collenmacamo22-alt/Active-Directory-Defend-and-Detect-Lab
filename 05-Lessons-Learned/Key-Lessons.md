# Key Lessons Learned

## Technical Lessons

- Authentication events should always be correlated.
- Failed logons alone rarely indicate compromise.
- Successful authentication following repeated failures deserves investigation.
- Privileged account monitoring should receive higher priority.
- Windows Event IDs provide valuable investigation context.
