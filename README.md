# Active Directory Defend & Detect Lab

## Overview

This project demonstrates my understanding of Active Directory security by documenting common attack techniques, defensive strategies, detection opportunities, and incident response procedures used in Windows enterprise environments.

Rather than focusing only on administration, this project emphasizes the security monitoring and detection responsibilities of a Security Operations Center (SOC) analyst.

---

## Objectives

- Understand Active Directory authentication.
- Identify common Active Directory attacks.
- Design practical detection logic.
- Practice Windows event log analysis.
- Improve incident response decision making.
