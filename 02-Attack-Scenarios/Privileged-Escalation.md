# Privilege Escalation

## Objective

This scenario demonstrates how an attacker attempts to obtain higher privileges within an Active Directory environment after gaining initial access.

---

## MITRE ATT&CK

**T1068 – Exploitation for Privilege Escalation**

Related techniques may also include:

- T1078 – Valid Accounts
- T1548 – Abuse Elevation Control Mechanism

---

## Scenario

An attacker successfully compromises a standard user account.

After gaining initial access, the attacker attempts to obtain administrative privileges to perform actions that would normally be restricted.

These actions may include disabling security controls, creating privileged accounts, modifying Group Policy, or moving laterally throughout the domain.

---

## Indicators of Compromise (IOCs)

Possible indicators include:

- Event ID 4672 (Special Privileges Assigned)
- Unexpected administrator logons
- Privileged logons outside business hours
- Administrative tools launching unexpectedly
- PowerShell executing administrative commands

---

## Detection Opportunities

SOC analysts should monitor for:

- Event ID 4672 generated by unexpected accounts
- Privileged accounts authenticating from unusual workstations
- Administrative activity immediately following successful authentication
- Privilege assignment followed by PowerShell, cmd.exe or certutil.exe execution

---

## Business Impact

Successful privilege escalation may allow an attacker to:

- Disable security software
- Create persistence
- Access sensitive information
- Move laterally across the network
- Fully compromise Active Directory

---

## Analyst Assessment

Event ID 4672 alone does not indicate malicious activity.

The event becomes suspicious when privileged accounts authenticate unexpectedly or when privileged sessions immediately perform unusual administrative actions.

Correlation between authentication events, privilege assignment, and subsequent process execution provides much stronger detection capability.

---

## Related Windows Events

- Event ID 4624 – Successful Logon
- Event ID 4672 – Special Privileges Assigned
- Event ID 4688 – Process Creation

---

## Related Detection Rule

Detection should correlate privileged logons with administrative process execution and unusual authentication behavior.
